# 词桥 · IELTS Vocabulary Reading Lab

面向中文学习者的静态雅思词汇阅读练习。网站包含 PDF 词表中的 538 个词项、20 篇原创英文阅读、100 道自动批改题，以及阅读译文、逐题解析和词汇语境例句。

## 本地使用

解压文件夹后，用浏览器打开 **index.html** 即可。网站不需要安装软件、后端服务或网络连接；字体使用设备自带字体。

答题记录、成绩、错题和收藏保存在当前浏览器的本地存储中。更换浏览器或设备后，记录不会自动同步。

## 发布到 GitHub Pages

1. 在 GitHub 新建一个公开仓库。
2. 将本文件夹内的全部文件上传到仓库根目录并提交。
3. 打开仓库的 **Settings → Pages**。
4. 在 **Build and deployment** 中选择 **Deploy from a branch**，分支选 **main**，目录选 **/(root)**，保存。
5. 等待 GitHub Pages 完成部署后，页面会显示公开网址。

更新网站时，将修改后的文件再次提交到同一分支即可。

## 内容说明

- 阅读文章为原创练习材料，不复制雅思真题。
- 词项保留 PDF 的分组、顺序、词性、中文释义和来源页码；同义替换提示计入 538 个词项。
- 每篇阅读附有可展开的目标词语境例句。客观题答案、得分和原文依据随静态页面提供。
- 本网站不调用 AI 或后端服务；写作题和主观题不在自动批改范围内。
